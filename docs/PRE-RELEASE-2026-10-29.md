# v0.1.0 发布前验收 / Pre-release review

日期：2026-10-29，Asia/Shanghai。目标：用户现有 Windows DSH Desktop **0.2.1-rc.3**，默认 `desktop` profile。候选版本 **0.1.0-rc.2**。本报告区分本轮直接实测、上一轮已验收范围及尚未覆盖项。

## 发布判断 / Release decision

**代码安装候选可供审查；含现有 KuroWhale 美术的完整 v0.1.0 尚不能公开发行。**

所有者明确选择代码 MIT、美术稍后决定。参考图来自网络蓝白鲸鱼娘，再由 ChatGPT 仿照生成；精确参考作者与完整改编/再分发许可仍待核清。只发布代码不能替使用者取得美术权利。没有重新生成美术，没有公开上传角色、参考图、角色截图、私有配置或原始诊断。

`rc.2` 相比已验收 `rc.1` 的桌宠功能代码仅改变版本标记；主入口、动画表、原生桥与前端在统一换行并忽略该标记后逐文件一致。本轮新增的是代码授权、依赖清单、可复现安装包和验收工具。没有增加非 MVP 功能。

## P1：运行稳定性与环境边界 / Stability and scope

本轮开始时 Desktop 未运行，状态文件过期约 17 小时；先启动现有应用，启动前记录不计入有效采样。用户确认所有任务结束并允许重启。中途按 Esc 暂停桌面控制时停止采样，用户明确继续后重新采样；间隔不算连续运行。

有效连续补采：**16:15:09–16:35:20，1210.423 秒（20 分 10 秒），1200 个样本**，同一原生进程树，始终七个进程；包含三次短隐藏/显示操作。采样间隔约一秒，实际总时间按记录时间戳计算。

此前 15:50:37–16:13:40 的安装/重启测试段中，52 个无原生进程的记录已剔除；最长连续观察 652.184 秒。

合计 **2519 个有效在运行样本**，分段观察时长之和 2535.893 秒（约 42 分 16 秒）；样本错误 0、格式错误 0。文件间暂停、重启和进程重建均拆段。最长连续观察只有 20 分 10 秒，**未完成 24 小时测试**。

连续补采首末一分钟的私有提交中位数分别为 171.825 / 183.685 MiB，增加 11.860 MiB。没有观察到旧原生进程持续残留，但这个短窗口不能排除持续内存增长，需要更长时间复测。

本轮私有验收脚本按唯一可执行路径及进程父子关系确认当前 DSH 根进程，只操作该进程树。报告中的这些 DSH 重启属于定向强制重启，不冒充已完成应用优雅退出验收；交付安装器本身不会结束进程。正常关闭与异常退出的桌宠原生进程树另行检查；不会结束其他应用的 WebView2。

实际显示环境：Windows 11 专业工作站版，build 26300，x64；一个主显示器，当前 WebView DPR=1.5。WinForms 返回的是 DPI 虚拟化坐标 1707×1067 / 工作区 1707×1019；前端按 DPR 换算并舍入的工作区为 2561×1529，不能混作另一台显示器或另一种 DPI，也不证明边缘换算无一像素舍入差。采样时 WebView2 版本为 156.0.4314.50。未修改系统缩放设置。

|scale|原生窗口宽×高|Canvas 物理宽×高|Canvas CSS 宽×高|
|---|---|---|---|
|0.5|202×139|96×139|64.00×92.67|
|1.25|240×347|240×347|160.00×231.33|
|2|384×555|384×555|256.00×370.00|

实际截图检查了缩放端点及恢复到 1.25 的角色，未见人物裁切。scale=0.5 时窗口实际宽 202、画布宽 96，有额外透明留白；这是已观察到的边界限制，未进一步归因。最低缩放下细节很小，不把它宣传为同等清晰。2.25 越界请求被拒绝，原 PID、scale=2 和渲染仍保留；随后恢复常用尺寸并居中。

没有覆盖 100%/125%/200% 系统 DPI、混合 DPI、多显示器热插拔、独占全屏、休眠唤醒及 24 小时运行。不能由本轮短时采样排除长期内存泄漏。

### 受控真实服务异常 / Controlled real service failure

在当前真实 Desktop 的临时验收插件中创建专属 Agent，通过其自己的 `system-prompt/assemble` 服务钩子抛出固定无害异常。没有手工发出 session 事件，没有修改模型配置或调用外部模型。

- `08:11:19.609Z`：真实 `turn/start`；`08:11:19.615Z`：故障钩子实际进入。
- `08:11:21.116Z`：固定异常实际抛出；`08:11:21.119Z`：真实 `turn/end(error)`，错误标识匹配预期。
- 桌宠快照为 `source=agent`，观察到 `idle → running → failed → idle`，原生渲染继续正常。

该测试在 `rc.1` 的同一功能代码上执行，随后升级 `rc.2`；没有伪称又对 `rc.2` 单独制造了一次模型 HTTP 错误。前期夹具缺少正确元数据或复用旧缓存，没有到达目标钩子的尝试不计通过。临时验收插件已移除。该证据验证 DSH 本地服务异常路径，不是远端 API 断网、429 或服务商故障端到端覆盖。

## P2：性能口径与结论 / Performance

CPU 使用真实进程 CPU 时间差，除以 32 个逻辑处理器折算整机百分比。Native 指 Neutralino 及其子进程。整个 DSH 的统计包含其他插件，不当作桌宠增量。

|场景|样本|整机 CPU 中位 / P95 %|工作集合计中位 MiB|私有提交中位 MiB|
|---|---:|---:|---:|---:|
|前期启动/服务验收段（rc.1 / rc.2）|1319|0.048 / 0.241|399.13|175.71|
|连续补采（rc.2）|1200|0.000 / 0.198|405.36|179.57|


另在同一 `rc.2` 进程树上使用 Windows 性能计数器采集三组数据，中位数：**工作集合计 405.77 MiB、私有驻留工作集 94.30 MiB、私有提交 179.74 MiB**。这些是 16:23:32–16:23:35 的点采样，不是整个观察区间的常驻平均值。

- 工作集是驻留页面；跨进程求和会重复计数共享页面，不能称为独占 RAM。
- `PrivateMemorySize64` / PrivateBytes 是私有提交量，可能部分换出，不能称为私有驻留内存。
- WorkingSetPrivate 是采样时的私有驻留页面。它也不包含所有共享、GPU、内核或系统增量开销，不能宣传“总共只占 94 MiB”。

保留稳定的 WebView2 多进程实现。隐藏时停止动画帧发送；未见值得冒渲染兼容风险替换架构的短时证据。约 400 MiB 的工作集合计和约 180 MiB 的私有提交仍应在试用说明中披露。较长时间和更多机器的内存变化需要后续测量。

## P3：安装包、复现与恢复 / Packaging and recovery

提供不含角色素材和运行时 exe 的 ZIP，其中有插件 tgz、依赖/许可清单、安装器、本地控制、性能采样/汇总工具及中英说明。构建只用 Python 标准库，显式白名单、固定文件顺序/时间/权限，禁止替换已锁定的第三方 JS。

最终代码 ZIP：`DSH-KuroWhale-0.1.0-rc.2-Windows-code.zip`，59928 字节。

SHA-256：`c6a74abc36b2789fb4d4676b359fb043ec8882fc681c1f2677193cd4602b382d`。

插件 tgz SHA-256：`3ed98eca066d825830b17c47d1f20e75e72bb560cf132d4667ecbc028f328b50`。最终包两次独立构建一致；Python 3.13.9、PowerShell 7.6.5、外部构建/控制 Node 24.19.0。工具版本不等同宿主内置 Node 版本。工作树设置 LF 文本及第三方原字节保留规则。

真实安装器完成运行中拒绝修改、错误校验后自动回滚、卸载、重装和冷启动；每次相关 UI 验收另行查看实际窗口。安装后的所有 11 个包文件与最终清单核验，不用 CLI 的“already up to date”当作代码已更新证明。

安装器固定使用目标 Desktop 内置 CLI，验证版本、外部 Neutralino exe 哈希、角色文件路径和 WebP 容器；原生解码器再核验实际图集尺寸。安装前必须结束任务并关闭 DSH；运行中会拒绝修改。它不创建 profile、不配置模型、不静默下载或安装运行时，只写自身配置。自定义 DSH_HOME 明确不支持。

备份包括插件包清单、锁文件、Cordis 文件和自有配置；复制字节而不解释模型凭据。失败时优先通过相同官方 CLI 恢复上一包，避免覆盖其他插件及较新的模型配置。备份和操作日志仅留本机。详细步骤见 [Windows 安装与恢复](WINDOWS-INSTALL.md)。

**全新 Windows 用户/干净系统安装仍未测试。** 已解压到全新目录、运行真实安装器及恢复流程不等于换了 Windows 账户、空缓存、空用户目录或干净机器。本轮没有为了此项新建系统账户、重装 DSH 或使用隔离 profile。公开完整下载到安装还受美术清权阻断。
