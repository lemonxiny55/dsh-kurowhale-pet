# v0.1.2 发布说明 / Release notes

v0.1.2 支持 DSH Desktop 0.2.1-rc.3 和 rc.5，默认启用 Windows x64 桌宠；缺少素材或 Neutralino 运行时时，自动获取并验证 SHA-256。已有路径、位置和显示设置予以保留。请从[安装指南](../README.md)选择 GitHub、Desktop 添加插件或市场入口；市场索引更新状态以首页为准。

v0.1.2 supports DSH Desktop 0.2.1-rc.3 and rc.5 and enables the Windows x64 pet by default. Missing artwork and Neutralino are downloaded and verified with SHA-256; existing paths, position and visibility settings are retained. See the [installation guide](../README.en.md) for GitHub, Desktop Add Plugin, and marketplace status.
