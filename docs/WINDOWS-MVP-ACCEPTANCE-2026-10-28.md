# Windows MVP 实机验收报告

日期：2026-10-28，Asia/Shanghai。目标：用户当前使用的 **Windows / DSH Desktop 0.2.1-rc.3**，现有 `desktop` profile；没有创建隔离 profile。运行时为 Neutralino 6.9.0，系统 DPI 为 150%。

## 结论

**达到本机环境的 v0.1.0 功能候选条件，当前保留安装 `0.1.0-rc.1`。尚不达到正式公开发行条件。**

九动画、交互、真实工具/审批、两会话优先级与中断反馈在 `0.0.3-dev.2` 完成实测；候选版只提升版本标记与使用文档，随后实际安装、冷启动并检查持续响应。它没有加入语音、养成或游戏功能。

美术再分发授权仍未确认；长期运行、其他 DSH 版本和跨显示器混合 DPI 尚未覆盖。代码仅提交开发分支，没有修改 main、创建 Release、发布 npm 或上传角色素材。旧 API 切换期间的轮次依用户要求不计入本次有效验收材料，以下 Agent 证据来自最终短验收。

## 真实 Agent 验收方法

临时、私有的 KuroWhale 验收工具只允许等待、通过实际 ApprovalService 请求单次审批、或返回固定结果；不访问文件、网络、shell 或凭据。由当前 DSH 的实际模型发起调用，在当前 Desktop 中显示审批。工具是测试夹具，验收后已卸载，不包含在候选包或 Git 提交中。

最终有效轮次的 UTC 时间（本地时间加八小时）：

- `13:25:51.078Z`：B 真实工具进入并请求审批。
- `13:27:25.175Z` 至 `13:27:55.191Z`：第二会话真实短等待工具执行；B 仍等待审批，桌宠保持 waiting。两会话状态快照已保存。
- `13:28:21.405Z`：通过桌面“允许一次”作出决定，outcome=allowed-once；桌宠恢复 running。
- `13:28:26.405Z`：审批工具返回固定结果。
- `13:28:57.303Z`：B completed，review，随后 idle。
- `13:31:23.428Z`：最终中断验收工具实际进入。
- `13:31:26.656Z`：测试程序只取消该测试 Agent；随后真实 turn/end(aborted)，failed，再 idle。此测试并未实际等待所请求的完整等待时长。

手工 `state`/`all` 只用于九动画诊断，开始真实任务前已经 resume。真实任务快照均为 `source=agent`。运行时的 `visibilityVerified=false` 表示它不能自动判断人眼可见性，不能拿这一字段替代本报告的截图和人工检查。

## 性能实测

采样范围：**21:19:19–21:39:28（Asia/Shanghai）**，1199 个有效样本，约一秒一次，采样错误为零，32 个逻辑处理器。数据来自最终候选所提升的同一功能代码 `0.0.3-dev.2`。候选版版本提升后的冷启动另外检查；没有将其伪称为完整重复了二十分钟采样。

CPU 以进程 CPU 时间差计算，并按 32 线程折算为**整机百分比**。内存为自己 Native 根进程及其子进程的工作集/私有内存之和；工作集可能重复计算共享页。DSH 一栏是整个应用，包含其他已有插件，并非 KuroWhale 的增量开销。

|场景|样本|Native CPU 中位数 / P95（整机 %）|Native 工作集中位数 MiB|Native 私有内存 MiB|DSH CPU 中位数（整机 %）|
|---|---:|---:|---:|---:|---:|
|空闲可见|771|0.048 / 0.198|410.45|181.82|0.100|
|诊断动画播放|96|0.050 / 0.294|409.26|183.69|0.050|
|真实 Agent 工作|58|0.146 / 0.573|409.00|181.98|0.605|
|真实审批等待|149|0.049 / 0.192|398.44|173.68|1.094|
|隐藏|14|0.000 / 0.243|401.15|183.82|0.120|

隐藏样本较少，P95 包含切换瞬间，不能用它推断长时间后台功耗。原生组合通常为一个 Neutralino 加六个 WebView2 进程；重建/启动期间观察到 5–7。采样有一次发现两个正在退出的旧子进程，后续五秒核验为零，不能将瞬时退出过程误称为泄漏。正常关闭和原生根进程强制退出的独立精确进程树检查均为零残留。

进程树使用创建时间校验父子关系，并以 PID+创建时间识别历史进程，避免 Windows PID 重用误算。其他应用原有的 WebView2 未终止。二十分钟没有观察到持续进程累积；这不代表长期内存泄漏已经排除。约 400MiB 的工作集仍有优化空间，不宣称极低内存桌宠。

## 本轮修复及真实失败

1. `Map.values()` 是一次性迭代器；原优先级函数反复展开会将工作误判为 idle。现在先收集一次。
2. 位置回报曾与移动指令共用广播事件，广播又会回到发送者，造成移动/回报自反馈。试验版本出现窗口退出及控制失联，已回退。现使用 `kw.reposition` 指令与 `kw.position` 回报；帧指令/回执也分为 `kw.frame` / `kw.rendered-frame`。
3. 回归测试将旧事件通道恢复后，单次初始化实际出现六次移动，测试失败；修复后只有一次，测试通过。这是代码回归证据，不替代后续真实 Desktop 验证。
4. 修正置顶原生参数，保存置顶设置；增加全窗口范围限制、越界恢复和可滚动的较大菜单，避免缩小时菜单裁切。
5. 隐藏保留托盘恢复入口，关闭/异常退出后可 show 重建；使用官方 extension 断开事件与连接状态检查，避免依靠页面计时误判宿主死亡。
6. 审批用 pending ID 集合保留优先级；hover 仅影响 idle，完成/中断反馈不会被紧随其后的 idle 通知抹掉。

早期试验失败和回退已保留在本次开发结论中；没有将它们改写为通过。定位后，在无反馈循环的版本中重新实测了核心功能。最终八项单元/回归测试通过。

## 环境保护、交付与剩余事项

开始时对七个相关配置文件作不解释内容的字节备份，并保存 KuroWhale 自有配置。整个过程没有读取、打印或修改模型 API Key/Token。用户在桌面中自行更换模型的设置被保留，没有用旧备份覆盖。失败时选择性恢复 KuroWhale；未删除其他插件、重置 profile 或重装 DSH。

最终保留候选插件，临时验收工具已卸载。原 dependencies/bundles 去除 KuroWhale 后一致；自身位置/缩放/可见性/置顶单独存储。恢复方法见 [插件 README](../plugin/README.md)。

本机 `.acceptance/` 留存候选包、配置备份和筛选后的有效截图/诊断，配置和私人日志不推送 Git。交付截图不是拼造的 WebView 成功回报；九动画拼图来自实际窗口捕获。代码授权与美术授权分别管理，不能将 Neutralino 的 MIT 授权扩展到角色素材。

剩余：美术再分发授权、跨显示器/其他 DPI、24 小时以上稳定性、其他 DSH 版本，以及独立服务错误分支的最终版回归。上述限制阻止正式公开发行，不妨碍将本机已验证版本用于下一轮功能候选试用。
