# DSH KuroWhale Pet v0.1.0 — Windows

免费、非官方的 DSH 桌宠，包含黑白鲸鱼娘角色、九种动画、插件、Agent 状态联动及 Windows 安装工具。请阅读包内安装说明。需 Windows x64、DSH Desktop 0.2.1-rc.3 的默认 desktop profile、PowerShell 7、Node.js 22.18.0 或以上、WebView2 和单独取得的官方 Neutralino 6.9.0 x64。长时间运行、混合 DPI、其他 DSH 版本和全新环境未充分验证；详见技术验收。
