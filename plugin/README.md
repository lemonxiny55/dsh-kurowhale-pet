# KuroWhale plugin

Windows desktop companion for DSH Desktop **0.2.1-rc.3**. The plugin reacts to Agent events and supports nine animation states, dragging, scaling, visibility, position persistence, a menu and tray controls. See the [technical acceptance record](../docs/TECHNICAL-ACCEPTANCE-0.1.0.md) for the tested scope and limitations.

## Install and configure

The [full Windows release](https://github.com/lemonxiny55/dsh-kurowhale-pet/releases/tag/v0.1.0) includes character assets and installation tools. The npm package includes character assets but does not enable rendering automatically. See the [npm and DSH Desktop guide](../docs/NPM-INSTALL.md) for prerequisites, plugin installation, configuration and safe removal. This repository's `plugin/` directory contains source code and the generic K tray icon; its `private` flag prevents accidental publication of that code-only source layout.
