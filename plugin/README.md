# KuroWhale 黑色系鲸鱼娘桌宠

Windows desktop companion for DSH Desktop **0.2.1-rc.3 and rc.5**. The published plugin version is **0.1.3**. It responds to Agent activity with nine animations and supports dragging, scaling, visibility, position persistence, a menu, and tray controls.

在 DSH Desktop 的“插件管理 → 添加插件”中输入 `dsh-kurowhale-pet@0.1.3`，选择 npm 官方源，安装后点击“立即启用”并重启。需要 Windows x64 和 WebView2；缺失素材与官方 Neutralino 6.9.0 运行时会从固定来源联网获取并校验 SHA-256。当前市场安装受旧索引阻塞。

In DSH Desktop, open **Plugin management → Add plugin**, enter `dsh-kurowhale-pet@0.1.3`, select the official npm registry, install, click **Enable now**, and restart. Requires Windows x64 and WebView2. Missing artwork and the official Neutralino 6.9.0 runtime are obtained from pinned sources and verified with SHA-256. Marketplace installation currently remains blocked by its stale catalog.

See the [中文 README](../README.md), [English README](../README.en.md), and [post-release acceptance record](../docs/POST-RELEASE-0.1.3.md) for installation entries and verified boundaries. The source layout is private to prevent accidental code-only publication; the published npm package is prepared with verified artwork by the [staging script](../scripts/stage-npm.mjs).
