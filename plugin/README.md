# KuroWhale plugin

Windows desktop companion for DSH Desktop **0.2.1-rc.3 and 0.2.1-rc.5**. The plugin reacts to Agent events and supports nine animation states, dragging, scaling, visibility, position persistence, a menu and tray controls. See the [technical acceptance record](../docs/TECHNICAL-ACCEPTANCE-0.1.0.md) for the tested scope and limitations.

**Release status:** npm 0.1.2 is published. Source 0.1.3 is a pending candidate and has not been published.

## Install and configure

Use the [GitHub URL, DSH Desktop Add Plugin, or marketplace](../README.en.md#installation-status). On Windows x64, missing artwork and Neutralino are downloaded and SHA-256 verified automatically. Existing explicit paths and settings are retained. The [v0.1.0 Windows ZIP](https://github.com/lemonxiny55/dsh-kurowhale-pet/releases/tag/v0.1.0) is an older alternative. This source-only directory is private to prevent accidental publication.
